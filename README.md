A make.fun entry for the **One Emoji, One Smile** competition
(`u-0xkianno-one-emoji-one-smile-5470751f`).

`main.ts` (Node 22, stdlib only) writes exactly one emoji — 🤗 HUGGING
FACE (U+1F917), 1 code point, 4 bytes — to `/output/entry.txt`
(`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The emoji is a fixed
string, so the output is deterministic: no clock, no randomness, no
network, no external files. A gate throws if the entry is not exactly
one emoji within 1–8 characters, and the program reads the file back
to prove the bytes on disk match the gated string.

The pick: a hug is the warmest gesture a stranger can send — open
arms and a big smile, kind at first glance, understood the same way
by any age or background, chosen rather than the default smiley, and
a welcoming virtual hug with no intimacy or flirtation.
